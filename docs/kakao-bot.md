# 카카오톡 봇 — 모바일 진입점 설계

## 왜 카카오톡 봇이 메인 진입점인가

- 자영업자의 99%는 카카오톡을 매일 씀
- 웹앱은 학습 부담 있음, 카톡은 학습 무 (이미 익숙)
- 알림톡은 SMS보다 열람률 3배 이상
- 딥링크로 다른 앱(네이버 블로그, 스마트플레이스 등) 자동 연결 가능

## 채널 · API 선택

### 알림톡 (Notification Talk)
- **채널**: 카카오 알림톡 (사업자 등록 필요)
- **API 제공사**:
  - **카카오비즈메시지** (kakaobiz.com) — 카카오 공식
  - **알리고** (aligo.in) — SMS/알림톡 통합
  - **팝빌** (popbill.com) — 서비스 다양
- **템플릿 심사**: 2주 정도, 사전 승인 필수
- **비용**: 건당 8~15원 (알림톡), 60원 (SMS 대체)

### 친구톡 (Friend Talk)
- 채널 친구 등록한 사용자만
- 이미지·이벤트 발송 가능
- 알림톡보다 자유도 높음

### 챗봇 (선택)
- **카카오 i 오픈빌더** (i.kakao.com) — 무료
- 대화형 흐름 만들 때
- MVP에선 알림톡 위주로 시작, 챗봇은 확장

## 대화 흐름 설계

### 온보딩 (최초 1회)
```
[사장님이 우리 채널 친구 추가]
봇 → "안녕하세요! 매장 정보 등록하러 가볼까요? [등록하기]"
사장님 [등록하기] 탭 → PWA로 딥링크
[PWA에서 정보 등록: 네이버 플레이스 URL, 업종, 로고 등]
→ 완료 후 다시 카톡으로 복귀
봇 → "등록 완료! 매일 아침 마케팅 활동을 도와드릴게요"
```

### 매일 아침 09:00 (블로그 반자동)
```
봇 → "[매장명] 오늘의 블로그 초안입니다
     '옥천 안내면 쿵더쿵 카페, 대청호 나들이길...'
     [보내기] [수정] [건너뛰기]"

사장님 [보내기] 탭
→ 봇: "네이버 블로그 앱을 열게요. 붙여넣기(길게 눌러 붙이기)로 아래 3단계 해주세요:
   1) 제목 자리에 붙여넣기
   2) 본문 자리에 붙여넣기
   3) 태그 자리에 붙여넣기
   준비됐어요! [블로그 앱 열기]"

사장님 [블로그 앱 열기] → 딥링크로 앱 오픈 + 클립보드 세팅
[앱에서 붙여넣기 3번 + 발행]
→ 사장님 앱 종료 후 다시 카톡으로 복귀
봇 → "발행 확인 완료! 오늘도 수고하셨어요"
```

### 부정 리뷰 발견 시
```
봇 → "⚠️ 방금 새 리뷰가 감지됐어요
     별점 ★★☆☆☆
     '음료가 미지근했어요...'
     
     답글 초안:
     '고객님, 죄송합니다. 방문 시간에 제가 자리 비운 사이 실수가 있었네요...'
     
     [답글 보내기] [수정] [무시]"

사장님 [답글 보내기] → 리뷰 원문 딥링크 + 답글 클립보드 세팅
→ 사장님이 앱에서 붙여넣기 → 완료
```

### 재방문 알림톡 (자동, 사장님 승인만)
```
봇 → "이번 주 재방문 유도 알림톡 대상 15명입니다
     예시:
     '홍길동님, 지난주 방문 감사드립니다. 이번 주 재방문 시 아메리카노 1잔 무료 쿠폰!'
     
     [승인해서 발송] [내용 수정] [건너뛰기]"

사장님 [승인해서 발송] → 서버가 15명에게 자동 발송
봇 → "발송 완료! 카카오톡으로 안내드렸어요"
```

## 딥링크 (앱 자동 오픈)

### 네이버 블로그
- `naverblog://write?blogId=USER_ID` — 앱에 write 화면 열기
- Fallback: 브라우저에서 `blog.naver.com/GoBlogWrite.naver`

### 네이버 플레이스 리뷰
- 웹: `m.place.naver.com/[type]/[placeId]/review`

### 배민 리뷰
- 배민 앱 딥링크 (사업자용)

### 인스타 (완전 자동이라 딥링크 불필요)

## 기술 구현

### 백엔드 (`backend/`)
- Node.js Express or Python FastAPI
- **알림톡 발송**: 알리고 API (초기), 후 카카오비즈 직결
- **크론**: 매일 09:00 KST 트리거 → 매장별 콘텐츠 생성 → 발송 큐 → 알림톡
- **웹훅**: 사장님 답변 처리 (수정·건너뛰기)

### 봇 폴더 (`bot/`)
- `bot/scheduler.ts` — 크론
- `bot/messenger.ts` — 알림톡 발송 래퍼
- `bot/flows/` — 대화 흐름 (onboarding, daily-blog, review-alert, alimtalk-batch)
- `bot/deeplinks.ts` — 앱 URL 스킴 관리
- `bot/clipboard-api.ts` — 사장님 탭 시 클립보드 세팅 endpoint

### 클립보드 세팅 트릭
카톡에서 사장님이 "보내기" 탭 → 우리 서버 URL 오픈 → 짧은 PWA 페이지가 열림 (`app.marketing-all-in-one.co/prepare?post=xxx`) → 이 페이지에서 `navigator.clipboard.writeText()` 실행 (사용자 탭이 있으니 권한 OK) → 딥링크로 앱 오픈

이렇게 하면 사장님 관점에선:
1. 카톡 알림 탭
2. 잠깐 화면 지나감 (클립보드 세팅)
3. 네이버 블로그 앱 자동 오픈
4. 붙여넣기 → 발행

**총 3~5초 대기, 5~7 클릭**. 원래 15분 작업이 30초로.

## 사장님 커뮤니케이션 톤

- "~요" 존댓말 유지 (사장님 대접)
- 이모지 활용 (친숙함)
- 간결 (자영업자는 바쁨)
- 실패 시 사과 정중히
- 성공 시 격려 ("오늘도 수고하셨어요")

## 채널 개설 절차 (사용자 액션)

1. 카카오 비즈니스 계정 (business.kakao.com) 로그인
2. 채널 개설 → 이름·프로필·소개 등록
3. 사업자 등록증 업로드 → 인증 (1~3일)
4. 알림톡 계정 개설 → 정산 정보 등록
5. 템플릿 3~5개 초안 작성 → 심사 (2주)

**MVP용 템플릿 후보** (미리 준비):
- T1: 오늘의 블로그 초안 안내
- T2: 부정 리뷰 발견 알림
- T3: 재방문 유도 (단골용)
- T4: 신규 이벤트 안내
- T5: 발행 완료 확인
