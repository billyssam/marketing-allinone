# 로드맵 — 마케팅올인원 v0.1

**목표**: 2026-09-30 파일럿 3~5명 온보딩 · 유료 전환 검증

## 🔥 3대 원칙 (설계·구현 항상 준수)

1. **프리미엄 SaaS 디자인** — Linear·Vercel·Framer·Cursor 벤치. "클로드틱" 완전 배제. shadcn/ui 커스터마이즈·Pretendard·정교한 색 팔레트·framer-motion.
2. **대시보드 = 데이터 시각화 중심** — 모든 결과 피드백은 차트·KPI·sparkline·감정분포·활동피드. 텍스트만 있는 대시보드 금지.
3. **B2B 배포 SaaS** — 자영업자 고객이 회원가입해서 쓰는 상품. 초기 Vercel 프라이빗 → 최종 **PWA + Capacitor 앱**으로 App Store/Play Store 배포.
