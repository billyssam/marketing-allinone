## 운영자가 해결해야 할 출시 조건

1. 메일: 발송 제한과 SMTP 구성 조회, 운영 발송 계정·도메인·SPF/DKIM·템플릿·redirect 점검 후 일반 고객 주소에서 가입 및 복구 수신 통과. 단일 승인 주소의 가입 성공으로 처리 용량과 전체 고객 발송을 보장하지 않는다. 현재 환경에 SMTP 자격증명이 없으며 SMTP 설정 자체는 조회하지 못했다.
2. AI: 운영 공급자 한도·결제 귀속 확인 후 승인된 비용 범위에서 실제 초안 생성·저장 검증. 장애와 키 설정은 운영자 책임이다.
3. 실기기: 알림 구독 → 푸시 실제 수신 → 초안 열기 → 실제 외부 게시 → 확인 저장의 전체 경로. 가상 게시 확인으로 대체하지 않는다.
4. 자동 연결: Meta·Google 앱 승인, OAuth·토큰 갱신·다중 계정 선택, 알림톡 심사, 운영자 Telegram 실제 전달. 직접 게시 초안 이용 가능과 자동 게시 준비 완료는 별개다.
5. 첫 설정 동시성: 순차 재진입/재시도 중복 방지는 수정했지만 동시 최초 요청에는 DB owner 유일 제약 또는 트랜잭션이 필요하다. DB 관리 도구 접근 거부로 이번에 적용하지 못했다.
6. Mac: 코드 백업과 실제 화면·로그인·확장 실행 복원을 별도 검증한다. Windows 중복 워커는 실행하지 않는다.
