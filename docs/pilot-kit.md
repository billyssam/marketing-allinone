## 4. 예상 질문(FAQ)

**Q. 인스타는 자동으로 올라가나요?**
아직요. 캡션을 자동으로 만들어 드리고, 복사해서 붙여넣으시면 됩니다. Meta 공식 API 연동은 준비 중입니다.

**Q. 매일 비슷한 글이 나오는 거 아닌가요?**
매일 각도(대표메뉴·분위기·팁…)×제목 구조×중심 소재를 바꿔서 씁니다. 한 달 동안 같은 조합이 반복되지 않게 설계돼 있어요.

**Q. 글 말투가 우리 가게랑 안 맞으면요?**
리뷰에서 매장 톤을 학습하지만, 안 맞으면 알려주세요. 피드백이 다음 글에 반영되도록 조정합니다.

**Q. 단골 알림톡은요?**
메시지 초안까지는 지금도 만들어 드립니다(`단골` 메뉴). 자동 발송은 알림톡 채널 심사가 끝나면 열립니다.

**Q. 내 가게 정보는 어떻게 관리되나요?**
개인정보처리방침(사이트 하단)에 그대로 적혀 있습니다. 탈퇴하면 설정 화면에서 즉시 전부 삭제됩니다.

**Q. 돈은 정말 안 내나요?**
3개월 파일럿 기간은 완전 무료입니다. 유료 전환은 최소 30일 전에 안내하고, 동의 없이 결제되는 일은 없습니다(이용약관 3조).

## 5. 운영 메모

- **Gemini 한도(실측)**: flash 무료 = 프로젝트당 **20회/일**. 데일리 크론은 매장당 flash 2회(기획+본문; 채널 네이티브 재작성은 lite 별도 쿼터) → **크론만이면 최대 ~10매장**, 사장님 수동 생성 여유를 두면 **6~8매장 권장**. 초과분은 flash-lite로 자동 폴백돼 끊기진 않지만 품질이 살짝 낮아짐 → 그 전에 Gemini 유료 전환.
- **감시는 자동**: 06:00 생존확인 → 07:30/08:30 생성(2중) → 09:30/10:30 "초안 실존" SLA 검증(2중) → 실패 시 GitHub 이슈→이메일. 조용하면 전부 정상.
- demo 계정(demo@example.com)은 파일럿 시작 전 데이터 정리 여부 결정.
- 소셜 로그인(카카오)은 등록되는 대로 가입 문턱이 더 낮아짐 — 초대 전 켜두면 좋음(`docs/oauth-setup.md`).
- 이메일 확인이 켜져 있으면 가입 후 메일 인증이 필요 — 파일럿 전 Supabase에서 확인메일 OFF 권장(초대 문턱↓).
