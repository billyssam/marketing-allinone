2. **바로**: 첫 블로그 초안이 자동으로 만들어져 대시보드에 등장 (~1분 내)

## 4. 예상 질문(FAQ)

**Q. 인스타는 자동으로 올라가나요?**
아직요. 캡션을 자동으로 만들어 드리고, 복사해서 붙여넣으시면 됩니다. Meta 공식 API 연동은 준비 중입니다.

**Q. 글 말투가 우리 가게랑 안 맞으면요?**
리뷰에서 매장 톤을 학습하지만, 안 맞으면 알려주세요. 피드백이 다음 글에 반영되도록 조정합니다.

**Q. 단골 알림톡은요?**
메시지 초안까지는 지금도 만들어 드립니다(`단골` 메뉴). 자동 발송은 알림톡 채널 심사가 끝나면 열립니다.

**Q. 돈은 정말 안 내나요?**
3개월 파일럿 기간은 완전 무료입니다. 이후 계속 쓸지는 사장님이 정하시면 됩니다.

## 5. 운영 메모

- 파일럿 규모에서 Gemini 무료 한도(20회/일)로 감당 가능 범위 = **매장 3~4곳** (매장당 2~3호출/일). 그 이상 받으려면 Gemini 유료 전환 선행.
- demo 계정(demo@example.com)은 파일럿 시작 전 데이터 정리 여부 결정.
- 소셜 로그인(카카오)은 등록되는 대로 가입 문턱이 더 낮아짐 — 초대 전 켜두면 좋음(`docs/oauth-setup.md`).
