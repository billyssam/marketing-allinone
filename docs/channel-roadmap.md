# 채널 확장 로드맵 — 마케팅올인원

**설계 원칙**: 채널은 플러그인. 고정 개수 없음. `shared/channels/registry.ts`에 정의만 추가하면
랜딩·대시보드·연결센터에 자동 노출. 사장님은 필요한 채널만 On/Off.

자동화 등급을 정직하게 표기 → 없는 걸 되는 척 안 함:
- `auto` 완전 자동 (공식 API) · `assisted` 반자동 (확장/딥링크 + 클릭) · `monitor` 크롤 읽기 · `beta` 준비중

## 채널 추가 SOP (새 채널 붙이는 표준 절차)
1. `registry.ts`에 `ChannelDef` 1개 추가 (id·group·automation·priority·actions)
2. `backend/channels/<id>/` 어댑터 구현 (connect / publish / fetch 인터페이스 통일)
3. 콘텐츠 엔진에 채널별 포맷 프리셋 추가 (글자수·해시태그·이미지 규격)
4. 연결센터·랜딩은 자동 반영 (레지스트리 기반 렌더)

## 어댑터 인터페이스 (모든 채널 공통)
```ts
interface ChannelAdapter {
  connect(store): Promise<Connection>;         // oauth/apikey/extension
  publish(post): Promise<PublishResult>;       // auto=서버발행 / assisted=클립보드+딥링크
  fetchMetrics(range): Promise<Metrics>;       // 도달·조회·전환
  fetchReviews?(range): Promise<Review[]>;      // 평판 그룹만
}
```
→ 채널마다 이 인터페이스만 채우면 대시보드·리포트·모니터링에 자동 편입.

## 콘텐츠 엔진 ↔ 채널 매핑
하나의 매장 정보 + 사진 → 채널별 자동 변환:
- 블로그: 1500자 SEO 글 + 사진 배치
- 인스타: 캡션 + 해시태그 30개 + 릴스 스크립트
- 플레이스 소식: 300자 + 이미지
- 알림톡: 승인 템플릿 변수 채움
- 스마트스토어: 상품 상세 HTML
- 리뷰 답글: 감정별 톤 초안
