# 사장님이 주셔야 하는 것 (2026-09-09 실측 기준)

> 초대 전에 이 문서를 그대로 보내면 됩니다. **없는 기능을 있다고 적지 않았습니다.**

## 1. 시작하는 데 필요한 것 — 5분, 앱에서 직접 입력

가입하고 5단계(온라인 판매는 4단계)만 지나면 다음 날 아침부터 글이 나옵니다.

| 항목 | 필수 | 왜 필요한가 |
|---|---|---|
| **상호** | ✅ | 블로그·인스타에 그대로 노출됩니다 |
| **업종** | ✅ | 43개 중 고르면 톤·채널·소재 각도가 전부 바뀝니다 |
| **파는 것 3~5개**(이름+가격) | ✅ | **1개만 적으면 매일 같은 소재로 씁니다.** 3~5개 적으면 매일 다른 것을 다룹니다 |
| 네이버 플레이스 주소 | 선택 | 넣으면 메뉴·영업시간·전화가 글에 자동으로 들어가고, **리뷰가 매일 수집**됩니다. 안 넣으면 위에 적은 것만으로 씁니다 |
| 채널 선택 | 선택 | 업종에 맞게 미리 골라뒀습니다. 그대로 두셔도 됩니다 |

⚠️ 온라인 판매(스마트스토어·프리랜서·과외)는 네이버 플레이스가 없으므로 그 단계가 아예 안 뜹니다.

## 2. 🔴 이걸 안 하면 아무 일도 안 일어납니다 — 알림 허용

**매일 글이 준비돼도 사장님이 앱을 열지 않으면 그냥 지나갑니다.**
지금 사장님께 닿는 경로는 **웹 푸시 하나뿐**입니다(카톡 알림톡은 아직 안 됩니다).

- **아이폰**: 사파리에서 열고 → 공유 버튼(⬆️) → **홈 화면에 추가** → 그 아이콘으로 다시 열기 → 알림 허용
  (아이폰은 홈 화면에 추가해야만 알림이 옵니다. 이 방법밖에 없습니다)
- **안드로이드**: 알림 허용만 누르면 됩니다

> 실제로 있었던 일: 한 사장님이 가입만 하고 알림을 안 켜셨습니다.
> 9일치 글이 만들어졌지만 **한 번도 도착하지 않았고**, 그분은 다시 안 오셨습니다.

## 3. 채널 연결 — 지금은 전부 '붙여넣기'입니다

정직하게 말씀드립니다. **자동 발행은 아직 한 건도 안 됩니다.**

매일 아침 채널별로 글이 완성돼 있고, 앱에서 **복사 → 앱 열기 → 붙여넣기** 3번이면 끝납니다.
(제목·본문·해시태그가 각각 복사되고, 네이버 블로그 앱을 바로 열어줍니다)

**그래서 사장님 아이디·비밀번호는 받지 않습니다.** 저희가 대신 로그인하지 않기 때문입니다.

## 4. 자동화를 켜려면 (선택 — 나중에, 사장님이 직접 발급)

지금 안 하셔도 됩니다. 하시면 이런 게 열립니다.

| 주시는 것 | 어디서 | 열리는 것 | 걸리는 시간 |
|---|---|---|---|
| Meta **App ID·Secret** | developers.facebook.com | 인스타 **자동 발행**(붙여넣기 없이) | 발급 10분 + **Meta 심사 4~6주** |
| 스마트스토어 **client_id·secret** | 판매자센터 → API 관리 | **매출 자동 수집** → "글 올린 날 vs 안 올린 날 매출" | 발급 10분 |
| 알리고 **API 키** | aligo.in | 단골 **알림톡 일괄 발송**(지금은 문자 앱 1탭) | 발급 + 템플릿 심사 2주 |

⚠️ **매출은 지금 한 건도 안 들어옵니다.** 스마트스토어 연동 코드는 껍데기 상태라
`client_id`를 주셔야 실제로 만들기 시작합니다.

## 5. 저희가 **절대 안 받는 것**

- 네이버·인스타 **비밀번호** (대신 로그인하지 않습니다)
- 카드·계좌 등 **결제 정보** (파일럿 기간 무료, 결제 기능 자체가 없습니다)

## 6. 파일럿 기간에 **없는 것** (미리 말씀드립니다)

첫 주에 기대하셨다가 실망하시면 안 되므로 먼저 적습니다.

- 자동 발행 ❌ (붙여넣기)
- 카카오톡 봇·알림톡 ❌
- 조회수·유입·전환 지표 ❌ (채널 연동 후에나 가능)
- 매출 연동 ❌
- 결제 ❌ (무료)

**되는 것**: 매일 아침 채널별 글 · 네이버 리뷰 자동 수집 · 부정 리뷰 폰 알림 ·
AI 답글 초안 · 단골 재방문 문자 · 주간 리포트.
