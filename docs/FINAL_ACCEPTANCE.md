# 전체 완료 조건

고객의 실제 경로와 운영자의 대응을 아래 근거로 닫는다. 단위 테스트 통과로 외부 운영 성공을 대신하지 않는다.

| 항목 | 완료 근거 | 현재 상태 |
| --- | --- | --- |
| 가입·로그인 | 일반 고객 가입 메일 인증, 로그인 및 복귀 | QA 가입 메일 수신·인증 성공, 일반 주소 발송 용량은 미검증 |
| 복구 | 실제 복구 메일 수신·링크 진입·재로그인 | 발송 제한, 관리자 SMTP 접근 필요 |
| 입력·첫 설정 | 필수 2개 입력·저장·중복 요청 안전 | 순차 여정 통과, 동시 요청 DB 유일성 미적용 |
| AI | 실제 공급자 응답 → 유효 초안 → DB 저장 → 고객 화면 | 무료 키 33.139초 및 운영 35.442초 각각 유효 초안 1개 저장·화면 확인. 운영 재시도 없음 |
| 채널 | 선택한 채널 생성, 해제 채널 제외 | 선택 로직 수정, 실제 생성 결과 대조 필요 |
| 알림 | 실제 기기 구독·서버 저장·발송·기기 수신·초안 진입 | 상태·저장 로직 통과, 실기기 수신 미검증 |
| 편집·게시 | 수정·복사·외부 편집기 입력·실제 게시·확인 | 실제 생성 본문 1,331자·9개 태그를 본인 블로그 비공개 1건 발행·화면·앱 확인 기록 통과. 공개 검색 노출 및 확장 주입은 별도 미검증 |
| 운영 감시 | 실패를 감지하고 운영자에게 실제 전달 | 실제 공개 가입에 맞춰 모드 선언 public으로 정정. SMTP 문제 감지는 유지. Telegram 수신처 미확인 |
| 보안 | 다른 고객 조회·수정·게시 차단 | 운영 경계 13개 통과 |
| 배포 | 동일 commit·Ready·health·실화면 | 최신 배포·CI 통과 |
| Mac | 최신 비공개 백업·재개·실제 화면 복원 | 프로젝트 별도 백업 uploaded and verified 확인. 화면 복원 미검증 |

## 최종 발견과 제한

- 운영 기본 주소에서 AI 요청 1회만 실행했고 HTTP 200, 35.442초, 저장 1개, 본문 2,343자, 두 메뉴 가격 유지 및 대시보드 표시를 확인했다. 승인된 운영 생성 재시도는 하지 않았다.
- 기존 무료 키 생성 본문을 본인 블로그 비공개 1건으로 실제 발행하고 9개 태그 저장과 앱의 게시 확인 기록까지 검증했다. 공개 검색 노출은 검사하지 않았다.
- PC 붙여넣기 안내를 키보드 단축키로 바꾸고 본인 블로그 글쓰기 화면을 새 탭으로 열도록 수정했다. 운영 기본 주소에서 실제 편집기 이동 확인.
- 실제 PC에 설치된 확장이 오래된 초안을 재노출하고 클립보드를 자동 변경하는 결함 발견. 배포 패키지 0.5.1에서 30분 만료, 초기 자동 복사 제거, 실제 복사 성공 후에만 성공 안내, 외부 출처 제한을 수정했다. 기존 설치본의 업데이트 및 실제 원클릭 주입은 미검증이다.
- Chrome 알림은 실제 차단 상태. 설정 화면 접근은 브라우저 자동화 보안 정책이 거부하여 사용자 직접 허용이 필요하다. 우회하지 않으며 테스트 알림은 아직 발송하지 않았다.
- GitHub 운영 비밀값 목록에 Telegram 토큰·수신처가 없어 운영자 메시지 전달 경로는 미설정이다. SMTP 관리 접근·SMTP 키, Aligo 및 Google OAuth 자격증명도 준비되지 않았다. 연결되지 않은 기능을 완료로 평가하지 않는다.
- Mac 원격 화면은 연결됨을 확인했지만 다른 작업 화면이었다. 코드 백업과 이 대화 화면 복원은 다르다. 현재 Windows 중복 워커는 실행하지 않는다.

## 실제 AI 검증 범위

- 가상 매장 1개, 블로그 짧은 초안 1회 요청. 실제 이름·주소·고객 자료는 사용하지 않는다.
- 기획·작성 2회가 기본이며 내부 파싱 재생성과 quota 폴백을 포함해 최대 6회 공급자 호출 가능. 외부 재시도는 하지 않는다.
- 무료 등급으로 확인된 기존 로컬 키를 사용하는 검증을 우선한다. 유료 전환·충전은 하지 않는다.
- 운영 키는 Vercel 비밀값으로 보호돼 로컬 키와 같은지 조회만으로 확인하지 못했다. 사용자 개인 청구·최대 1,000원 승인에 따라 운영 요청 1회만 허용한다. 기획·작성·폴백 응답 각각 최대 8,192 토큰으로 제한한다.
- 생성 후 제목·본문·태그·채널·상태·DB 저장을 확인하고 가상 데이터와 계정을 정리한다.
