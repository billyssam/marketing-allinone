# 마케팅올인원 — 네이버 원클릭 확장

붙여넣기 3번을 **버튼 하나**로 바꿉니다.

| 채널 | 확장 없을 때 | 확장 있을 때 |
|---|---|---|
| 네이버 블로그 | 제목·본문·태그 3번 붙여넣기 | 버튼 → 에디터에 제목·본문이 채워짐 |
| 네이버 플레이스 소식 | 본문 붙여넣기 | 버튼 → 소식 작성칸에 채워짐 |

다른 채널(인스타·스레드 등)은 그대로 붙여넣기입니다. 확장을 **안 깔아도 앱은 똑같이 동작합니다.**

## 설치 (5분, 크롬)

1. 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭
4. 이 폴더(`마케팅올인원/extension`) 선택
5. 목록에 "마케팅올인원 — 네이버 원클릭"이 뜨면 끝

## 확인하는 법

1. 앱에서 블로그 초안의 **[붙여넣기 →]**를 누른다
2. 화면 위에 **⚡ 네이버 블로그에 바로 채우기** 버튼이 보이면 확장이 잡힌 것
   (안 보이면 확장이 안 깔렸거나 페이지를 새로고침해야 한다)
3. 누르면 네이버 글쓰기 탭이 열리고 제목·본문이 채워진다
4. 내용 확인하고 **발행**만 누르면 끝

플레이스는 같은 방식으로 **⚡ 플레이스 소식에 바로 채우기**가 뜬다.

## 안 될 때

**버튼이 안 보인다** → `chrome://extensions`에서 켜져 있는지 확인하고 앱 페이지 새로고침.

**버튼은 눌리는데 네이버 화면에 아무 일이 없다** → 네이버가 화면 구조를 바꾼 것이다.
그럴 때 확장은 **조용히 넘어가지 않는다** — 오른쪽 아래에 "입력칸을 못 찾았어요,
글은 복사해 뒀습니다"가 뜬다. 그대로 붙여넣으면 되고, 알려주면 셀렉터를 고친다.

## 개발자용

```
extension/
  manifest.json   MV3. 블로그·플레이스·우리 앱 세 곳에 content script
  bridge.js       웹앱 ↔ 확장 다리(postMessage). 확장 ID 불필요
  content.js      네이버 블로그 SmartEditor 주입(제목+본문)
  place.js        플레이스 소식 주입(본문만)
  background.js   초안 보관 + 채널별 글쓰기 탭 열기
```

⚠️ **자동 검증의 한계**: `backend/src/test-extension-bridge.ts`가 다리 규약 7건을 검증하지만,
**Chrome이 확장을 싣는 것**과 **네이버 에디터에 실제로 채워지는 것**은 검증하지 못한다
(헤드리스는 확장 미지원, 헤드 모드는 CI에서 안 뜸, 네이버는 로그인 필요).
그 두 구간은 사람이 위 "확인하는 법"으로 봐야 한다.
