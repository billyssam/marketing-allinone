# 마케팅올인원

자영업자를 위한 마케팅 종합 SaaS. 한 번 등록하면 인스타·블로그·알림톡·리뷰 대응이 자동/반자동으로 굴러가는 풀패키지.

> ⚠️ 이 프로젝트는 **CARTON과 무관**합니다. 다른 자영업자 SaaS(`Pre-Service-Blog-Instagram`)와도 별도 유지 — 참조·자산 재활용만.

## 무엇을 해결하나

**자영업자의 실제 문제**:
- 마케팅은 해야 하는데 뭘 어떻게 할지 모름
- 인스타·블로그·알림톡·리뷰 대응이 다 따로 놀아서 뇌 폭발
- 컨설팅 받으면 월 수백만원, 결과도 애매
- 대부분 모바일로 일하는데 툴은 다 PC 전용

**우리 답**:
- 매장 정보 한 번 등록 → AI가 모든 채널 콘텐츠 자동 생성
- 인스타·알림톡·SMS = 완전 자동
- 블로그·플레이스·리뷰답글 = 카톡 봇이 안내하면 사장님 3단계 붙여넣기
- 모바일 우선 (카카오톡 봇이 메인 진입점)

## 구조

```
마케팅올인원/
├─ web/         # PWA 대시보드 (Next.js 16 + Tailwind v4 + shadcn/ui)
├─ backend/     # API 서버 · 크롤 · 채널 통합
├─ bot/         # 카카오톡 봇 (모바일 진입점)
├─ shared/      # 공통 콘텐츠 엔진 · 타입
└─ docs/        # 로드맵 · 아키텍처 · 채널별 노트 · 의사결정 로그
```

## 스택

- **PWA**: Next.js 16 · Tailwind v4 · shadcn/ui · Service Worker
- **Auth**: Supabase (카카오 OAuth)
- **DB**: Supabase Postgres
- **AI**: Gemini (콘텐츠) · Claude (답글)
- **크롤 서버**: Oracle VM (CARTON에서 검증)
- **채널 API**: Meta Graph · 카카오 알림톡 · 알리고 SMS · Google GBP · Naver 톡톡
